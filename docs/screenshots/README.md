**Recording a GIF (macOS):** [Kap](https://getkap.co) (free) or [CleanShot X](https://cleanshot.com) both export GIF directly. Aim for ~800px wide and under ~5MB — trim to the essential 10–15 seconds so it stays snappy.

**Static screenshots:** ⌘⇧4 (macOS) or your OS equivalent, or use the browser's own screenshot tool for a clean crop without the address bar.
